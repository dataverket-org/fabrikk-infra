# Research

Notes from exploration that concern this repository: the cluster it runs, the storage under it, the way its
manifests are rendered and shipped. Each note says what was read and what was run, and lists what remains to be
proven. A note is not a decision; a decision in `docs/decisions/` points at the note it rests on.

Notes about Dataverket as a whole, the products, the tenancy model, the choice of software across sites, live in the
`org` repository under `docs/forskning/`, and a note here points there when it hands a question over.

The notes are written in LLM sessions and read by a person before they are committed.
