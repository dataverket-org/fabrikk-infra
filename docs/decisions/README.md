# Decisions

Why this repository is shaped the way it is. One file each: the problem, the decision, and what follows from it.
The README says what is where, `bootstrap.sh` says how, these say why.

A number is an identity and nothing else. It does not say when a decision was taken, and it does not say what the
decision is about: a new one takes the next free number whatever its subject, so the grouping below comes from
each file's `category:` field and not from the order of the numbers. This page is generated by `bin/decisions`; edit
the decisions, not the index.

A decision is not edited to change its meaning after it is accepted. A change of mind is a new record that says
what it supersedes.

| [021](021-git-describes-the-cluster.md) | Git describes the cluster; a rebuild restores its databases | Every change ends with the cluster matching git, and each database's recovery source is in git, so Flux rebuilds the cluster with its data. | 2026-10-01 |
| [022](022-the-forge-mirrors-the-actions-its-workflows-use.md) | The forge mirrors the Actions its workflows use | An actions org on the forge holds pull mirrors of the Forgejo project's actions org, made and kept by the forge's own install; workflows pin a mirrored action by commit. | 2026-10-04 |

| [027](027-the-control-plane-carries-the-names-and-certificates.md) | The control plane also carries the cluster's names and certificates | cert-manager, external-dns and the DNS provider webhook run on the control planes, as the cloud credential's holders do; the webhook is three replicas spread over them, everything else one; Flux stays on the workers because it writes to the etcd disk. | 2026-10-06 |
| [028](028-upstream-charts-are-rendered-in-the-factory.md) | Upstream charts are rendered in the factory and shipped as artifacts, chart by chart | A chart is inflated by kustomize on the operator's machine into a committed rendered tree, reviewed as a diff, shipped as a signed OCI artifact and applied by Flux; helm-controller leaves the cluster when the last HelmRelease does; cert-manager and external-dns go first. | 2026-10-06 |
