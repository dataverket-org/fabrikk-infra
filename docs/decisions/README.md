# Decisions

Why this repository is shaped the way it is. One file each: the problem, the decision, and what follows from it.
The README says what is where, `bootstrap.sh` says how, these say why.

A number is an identity and nothing else. It does not say when a decision was taken, and it does not say what the
decision is about: a new one takes the next free number whatever its subject, so the grouping below comes from
each file's `category:` field and not from the order of the numbers. This page is generated by `bin/decisions`; edit
the decisions, not the index.

A decision is not edited to change its meaning after it is accepted. A change of mind is a new record that says
what it supersedes.
